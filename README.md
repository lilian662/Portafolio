#  Portafolio de Proyectos Académicos y Profesionales

Bienvenido/a a mi portafolio. En este repositorio concentro mis proyectos más relevantes enfocados en **Web Scraping, Econometría, Simulación Estocástica y Análisis de Datos**.

##  Índice de Proyectos

###  1. Web Scraping y Comparativa de Ofertas (Liverpool)
- **Documento:** [`Informe - Proyecto Audifonos Liverpool (1).pdf`]
- **Código y Carpetas:** [`01_Web_Scraping_Liverpool`](./01_Web_Scraping_Liverpool/)
- **Técnicas:** Web Scraping (Selenium), Procesamiento de Datos (Pandas), Visualización (Matplotlib).
- **Descripción:** Extracción automatizada de más de 1,800 productos en tres periodos promocionales (Normal, Black Friday y Venta Nocturna) para evaluar la veracidad de los descuentos y detectar aumentos previos de precio.

---

### 2. Modelo Econométrico de Precios Hedónicos
- **Documento:** [`Ingeniería_Proyecto-1.pdf`]
- **Técnicas:** Regresión Lineal Múltiple OLS, Precios Hedónicos (Teoría de Rosen), Diagnósticos de Gauss-Markov.
- **Descripción:** Estimación del valor implícito de atributos (*Brand Equity*, conectividad inalámbrica, diseño *over-ear* / *in-ear*, uso *gaming* / deportivo) sobre el precio final de los productos.

---

### 3. Simulación Estocástica & Monte Carlo
- **Notebooks:** [`proyectofinalsimulaccionII.ipynb`]
- **Técnicas:** Algoritmos de Monte Carlo, Cadenas de Markov, Simulación de Eventos Discretos.
- **Descripción:** Implementación de modelos probabilísticos en Python para la estimación de costos promedio, escenarios de riesgo y teoría de colas.
